# BookMyStay Hotel Booking System

- **UC1: Room Inventory Management**
  - Add room types (Single, Double, Suite)
  - Update room counts and prices
  - Show availability

- **UC2: Room Search**
  - Search available rooms
  - Check specific room availability

- **UC3: Booking Request (FIFO Queue)**
  - Guests add booking requests
  - Requests processed in arrival order
  - Simulated delay (`Thread.sleep`) between bookings

- **UC4: Reservation Confirmation & Room Allocation**
  - Assign unique room IDs
  - Prevent duplicate allocations
  - Update inventory instantly

- **UC5: Add-On Service Selection**
  - Attach optional services (Breakfast, Spa, Pickup)
  - Multiple services per reservation
  - Calculate additional service cost

- **UC6: Booking History & Reporting**
  - Store confirmed reservations
  - Support cancellation
  - Generate booking history reports
  - Count total reservations
